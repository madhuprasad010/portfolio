01. About me

I'm an engineer who cares about the things users never see — the milliseconds shaved off an API call, the message that survives a broker outage — and, increasingly, the things they do see: the dashboards and health pages that tell you at a glance that everything is running.

At Cognizant, working on Cargill's global supply-chain platforms, I've migrated a legacy monolith to API-first Spring Boot microservices, built Kafka and RabbitMQ event pipelines handling 100K+ events a day, and shipped containerized services to AWS with Docker, Kubernetes and Jenkins. On the front end, I build React (Hooks, Redux) and Angular ops dashboards and health/ping pages — tested with Jest, built with Vite — that smoke-test those backends in real time.

Beyond code, I mentor junior engineers, lead code reviews, and take P1/P2 incidents personally — cutting our mean time to recovery by ~45%.

  • Cut API latency from 800ms to 120ms with Redis caching & query tuning
  • Monolith → microservices migration, ~35% faster delivery
  • React ops dashboards & ping pages that smoke-test every service
  • Idempotent APIs, retries & dead-letter queues for high availability
  • 90% test coverage with JUnit 5, Mockito & Testcontainers
